# TimeBox

TimeBox — конструктор игр: ученик собирает код игры на JavaScript по квестам. Слева код по
вкладкам и гайд, справа игра. Игры:

- **Корзинка** (очень легко, адрес `?game=catch`): сверху падают яблоки, внизу ездит герой.
- **Птичка** (легко, как Flappy Bird): птица падает, пробел — взмах, навстречу едут трубы с дыркой.
  Новое — скорость: гравитация прибавляется к скорости, скорость — к высоте.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Без параметров открывается главное меню с выбором игры; `?game=catch` или `?game=bird` — сама игра.

`?game=<id>&finished` (для Корзинки — и просто `?finished`) — готовая версия игры со своим сохранением:
у Корзинки — бомба, звезда, +10 очков, ускорение; у Птички — монетки и ускорение труб.
Она открывается по паролю учителя (в коде лежит только хеш; это защита от случайного
открытия, а не настоящая).

## Скрипты

| Команда                | Что делает                                                              |
| ---------------------- | ----------------------------------------------------------------------- |
| `npm run dev`          | дев-сервер Vite                                                         |
| `npm run build`        | проверка типов + сайт в `dist/` (Vercel, GitHub Pages)                  |
| `npm run build:single` | один файл `dist-single/hitbox.html` для работы без интернета            |
| `npm test`             | юнит-тесты (Vitest): склейка, синтаксис, переводы, логика игры          |
| `npm run test:e2e`     | сквозные проверки (Playwright): файл через file:// и сайт в `/hitbox/` |
| `npm run check`        | линтер, сборка и юнит-тесты                                             |
| `npm run lint`         | линтер (oxlint)                                                         |
| `npm run preview`      | локальный просмотр собранного `dist/`                                   |

## Где открыть

- **Vercel** — https://timeboxcl.vercel.app, собирается сам из основной ветки.
- **GitHub Pages** — https://xrnskew.github.io/hitbox/, запасной адрес (vercel.app из России
  без VPN открывается плохо). Собирает `.github/workflows/pages.yml` при пуше в основную
  ветку; сайт лежит в подпапке, поэтому сборке передаётся `BASE_PATH=/hitbox/`
  (на Vercel и локально — `/`).
- **Без интернета** — `dist-single/hitbox.html` (`npm run build:single`): один файл со всем
  внутри (код, стили, шрифты), открывается двойным кликом в Chrome с флешки, без сервера.
  Готовый файл есть и на Pages: https://xrnskew.github.io/hitbox/hitbox.html (сохранить
  как…), и в артефакте `hitbox` у каждого запуска workflow в Actions.

Роутинга нет: готовая игра — это тот же адрес с `?finished`, поэтому прямые ссылки и
обновление страницы на Pages не дают 404.

## Что умеет

- Код по вкладкам «Движок → Герой → Яблоки → Поимка», у каждой вкладки своя история отмены.
- Гайд по шагам: крупные кнопки «Вставить», «Показать код», «Как это работает». После каждого
  шага задание, и только оно открывает следующий шаг: своя корзина, ускорение `speedUp`
  (части всплывают прямо в коде «Яблок» с кнопкой «Добавить»), а за ним второй квест — заменить
  🍎 на свой смайлик; в шаге 3 — 10 очков за яблоко.
- «Собрать» (Ctrl+Enter) склеивает вкладки и запускает игру.
- Прогресс в шапке — пять галочек: три шага и бомба со звездой.
- Бомба и звезда — после сборки игры: одна кнопка добавляет переменную в «Движок», вторая
  вставляет код сразу в «Яблоки» и «Поимку».
- Ошибки с вкладкой и строкой на понятном языке; синтаксис проверяется ещё во время печати.
- Подсказки к именам движка (автодополнение и при наведении мыши).
- «Приборы» (значения переменных), консоль для `console.log`, показ зоны поимки («Границы»).
- Стабильные 60 кадров на мониторах 120/144 Гц, чёткий холст на Retina.
- Сбросы с подтверждением и отменой, сохранение в браузере, рекорд.
- Игра живёт в карманной приставке: кнопки ← → на корпусе работают мышью и пальцем.

## Структура

```
src/
  main.tsx, App.tsx       точка входа и раскладка
  app/                    контроллер (вся логика) и маленький внешний стор
  core/                   чистые модули: склейка, синтаксис, переводы ошибок, прогресс,
                          уровни (что открыто), пароль готовой игры
  lessons/index.ts        список игр — из него строится главное меню
  lessons/kit.ts          общие помощники квестов: куда вставить кусок, как проверить
  lessons/catch/          урок Корзинка: код вкладок, гайд, задания, подсказки
  lessons/bird/           урок Птичка — устроен так же
  sandbox/                обвязка iframe (runtime.js), сохранение
  editor/                 CodeMirror: вкладки, тема, подсказки, всплывающие куски кода
  components/             интерфейс
  styles/                 токены, база, общие примитивы
  assets/fonts/           Unbounded, Onest и JetBrains Mono (woff2, OFL)
tests/unit/               Vitest
tests/e2e/                Playwright
docs/SPEC.md              ТЗ
docs/PLAN.md              план и предложения
```

Импорты из `src` можно писать через алиас `@/`, например `import App from '@/App'`.
Модули `src/core` импортируют друг друга относительными путями — их можно запускать в Node напрямую.
