# ТЗ: песочница «Лови яблоки»

Исходное ТЗ от пользователя (версия 1, на JS + Tailwind). Версия 2 в этом репозитории
сохраняет все механизмы ниже, но отличается в нескольких местах — они перечислены в конце.

## 2. Игра

Сверху падают яблоки, внизу ездит корзина. Поймал — очко, уронил — минус жизнь. Три жизни.
Когда жизней 0, движок останавливает логику и пишет «Игра окончена». Поле 380×470, рисуется
на `<canvas id="game">` через `ctx`. Управление стрелками ← →.

### Вкладки (порядок склейки фиксирован)

| # | id | Название | Что внутри | Функции ученика |
| --- | --- | --- | --- | --- |
| 0 | engine | Движок | Настройки, состояние, клавиши, заготовки, главный цикл. Выдан готовым | — |
| 1 | hero | Герой (шаг 1) | Движение и отрисовка корзины | movePlayer, drawPlayer |
| 2 | apples | Яблоки (шаг 2) | Появление, падение, отрисовка | moveItems, drawItems |
| 3 | catch | Поимка (шаг 3) | Поймал или уронил | checkCatch |

У каждой вкладки есть `note` — однострочная подсказка над редактором.

### Движок учебной версии

Готовый движок без двух строк `bombEmoji` и `goldEmoji` (их ученик добавляет сам в задании
про бомбу и звезду). С версии 5 в нём нет и `playerEmoji` (её создают в «Герое»), а `playerSpeed` и `fallSpeed` — 0.
Текст — в `src/lessons/catch/tabs.ts` (`TUTORIAL_ENGINE`).

**Заготовки.** Пустые `function movePlayer() {}` и т.д. в «Движке» перекрываются функциями
ученика с тем же именем из следующих вкладок за счёт всплытия объявлений: в одном скрипте
побеждает последнее объявление. Поэтому игра запускается с самого начала, когда ученик ещё
ничего не написал. «Движок» всегда склеивается первым.

### Пустые вкладки учебной версии

Вместо пустоты — комментарий:

```js
// Шаг 1. Здесь будут функции movePlayer и drawPlayer.
// Не знаешь, с чего начать? Открой вкладку «Гайд».
```

Для «Яблок» и «Поимки» текст тот же, но шаг и функции свои.

### Готовая версия

`FINISHED_TABS`: бомба 💣 (поймал — минус жизнь), звезда 🌟 (плюс жизнь), +10 очков, ускорение
каждые 15 секунд до потолка 8. Открывается по `?finished`: своё отдельное сохранение, гайда
нет, под игрой список «Что тут есть».

## 4. Механизмы, которые нельзя ломать

### 4.1. Склейка и запуск через srcdoc

`buildDoc(codes, …) = PREFIX + codes.join('\n') + SUFFIX`. Каждый запуск — новый iframe
целиком: `<iframe key={runId} srcDoc={doc}>`, `runId++` на каждый запуск. Без
sandbox-атрибута: srcdoc-iframe того же происхождения, и `contentWindow.focus()` работает.
Всё равно оборачивать в try/catch. Холст в обвязке: `canvas{width:100%;height:auto}`, а
внутренний размер остаётся 380×470.

### 4.2. Обвязка iframe — два скрипта

Первый скрипт — обвязка: `window.onerror → postMessage({type:"err", message, line})`, FOCUS,
`mousedown → window.focus()`, стрелки → `preventDefault`, Ctrl/Cmd+Enter →
`postMessage({type:"run"})`. Второй — `var canvas, ctx; try { …код вкладок… } catch (e) { … }`.

`onerror` обязан стоять в отдельном, первом скрипте: если он в одном скрипте с кодом ученика,
синтаксическая ошибка не даёт скрипту запуститься вовсе. У пойманной ошибки номер строки
есть только в стеке: `/srcdoc:(\d+)/.exec(e.stack)`, а в onerror передают `String(e)` — с
именем. Родитель принимает сообщения только от текущего iframe:
`e.source === frameRef.current.contentWindow`.

### 4.3. Фокус

Клавиши ловятся только внутри iframe. После загрузки игра забирает фокус, по клику
возвращает его себе. Стрелки внутри iframe не прокручивают страницу. Исключение: если до
запуска нашли синтаксическую ошибку, игра не стартует, и фокус остаётся в редакторе; число
строк обвязки при этом не меняется. Под игрой индикатор: «Кликни по игре, потом двигай ← →»
или «Двигай корзину ← →». Рамка подсвечивается.

### 4.4. Карта строк для ошибок

`HEADER_LINES = PREFIX.split('\n').length - 1` считается автоматически. `locate(globalLine,
codes)` отнимает HEADER_LINES и проходит по вкладкам (длина — `code.split('\n').length`).
Считать по коду на момент запуска. Формат: `Ошибка во вкладке «Поимка», строка 3: …`. Если
строку определить нельзя — `Ошибка: …`.

### 4.5. Синтаксис проверяется до запуска, по вкладкам

`acorn.parse(code, {ecmaVersion:'latest', sourceType:'script'})`. Если ошибка есть —
дополнительно сканер скобок (пропускает строки и комментарии, стек `([{`, лишняя или не та
закрывающая, эвристика отступов для незакрытой `{`). Берётся ошибка с меньшим номером строки.
Первая по порядку склейки вкладка с ошибкой — ответ; пока он есть, синтаксические сообщения
из iframe игнорируются.

Переводы: Unexpected token → «здесь что-то лишнее или чего-то не хватает», «скобка { открыта,
но не закрыта — не хватает }», «не закрыта кавычка». Ошибки выполнения переводятся частично,
оригинал в скобках, префикс Uncaught убирается:

- `X is not defined` → «X не найдено — проверь, нет ли опечатки в имени»
- `X is not a function` → «X — не функция, её нельзя вызвать со скобками»
- `Cannot read properties of undefined (reading 'y')` → «нельзя взять .y у пустого значения undefined»
- `Identifier 'a' has already been declared` → «имя a уже объявлено в другой вкладке или выше»

Строка с ошибкой подсвечивается в редакторе (StateField, сбрасывается при правке). Кнопка
«Показать» открывает вкладку, ставит курсор на строку и прокручивает к ней.

### 4.6. Сохранение

`localStorage['catch-sandbox-v1']` — массив строк по числу вкладок; у готовой версии
`catch-sandbox-finished-v1`. Активная вкладка — `<ключ>:active`. Запись через 400 мс после
печати, плюс сразу при запуске, при смене вкладки и на pagehide. Всё в try/catch. Битые
данные или неверная длина — стартуем с исходного кода.

## 5. Редактор (CodeMirror 6)

Один EditorView и по одному EditorState на вкладку: у каждой вкладки своя история отмены.
Расширения: lineNumbers, highlightActiveLine(Gutter), drawSelection, history, indentOnInput,
bracketMatching, javascript(), syntaxHighlighting(classHighlighter), tabSize 2, indentUnit
'  ', indentWithTab. Mod-Enter и Ctrl-Enter — запуск (Prec.highest); Ctrl-z / Ctrl-Shift-z /
Ctrl-y явно. Тема с `{ dark: true }`. Подсветка — классы `tok-*`, те же в блоках кода гайда.
Лигатуры выключены. Программные правки — одной записью в историю (`isolateHistory.of('full')`),
в том числе для неоткрытой вкладки; undo тоже работает для неоткрытой вкладки. Редактор
монтируется один раз и под гайдом скрывается; гайд тоже не размонтируется.

## 6. Гайд

Отдельная вкладка «Гайд» первой. В учебной версии открыт при первом запуске. Тон — для
подростка, который программирует впервые: коротко, на «ты», каждая мысль привязана к экрану.

- **Вступление.** Что за игра, слева код, справа игра, порядок склейки, «Движок» уже написан,
  запуск кнопкой или Ctrl+Enter, клик по игре, Ctrl+Z, ошибки с вкладкой и строкой.
- **Три шага.** «Шаг N из 3», заголовок, «Сделано / Не сделано», 2–4 абзаца, подпись вкладки,
  кнопка «Вставить во вкладку «…»», блок кода с номерами строк, «Можно не вставлять, а
  перепечатать руками — так лучше запомнится», блок «Проверь». Вставка заменяет вкладку одной
  правкой, переключает на неё, уведомление «…Теперь нажми «Запустить»» с «Вернуть как было».
  «Сделано»: все функции шага объявлены и не пустые (комментарии вырезаются).
- **Задания без готового кода:** «Своя игра», «Десять очков», «Всё быстрее».
- **Бомба и звезда** (задания 4 и 5) — по три части: эмодзи в «Движок» (одна строка после
  последней `var …Emoji`, иначе после `// ===== НАСТРОЙКИ`; если уже есть — показать строку,
  уведомление без отмены), новый код «Яблок» и «Поимки» (замена вкладки). Бомба:
  `Math.random() < 0.2`. Звезда: `r < 0.18` → bomb, `r < 0.26` → gold, иначе apple. Упустить
  бомбу или звезду не страшно. Под разделом — предупреждение про перезапись.

## 7. Сбросы и отмена

- Сброс вкладки — кнопка над редактором, окно «Код в этой вкладке вернётся к началу. Другие
  вкладки и настройки в «Движке» останутся как есть».
- «Движок» — жёлтая кнопка «Сбросить движок», окно «Твои настройки пропадут», фокус на «Отмене».
- «Сбросить всё» — неброская кнопка в шапке, красное предупреждение, подтверждение словом
  «сброс». Сбрасываются только изменённые вкладки. После — гайд, перезапуск игры, уведомление
  30 секунд с «Вернуть как было».
- Любой сброс обратим (Ctrl+Z / Ctrl+Shift+Z). После закрытия окна фокус — в редактор.
- Окна — нативный `<dialog>` + `showModal()`, клик по фону закрывает.

## 8. Интерфейс

Тёмная тема в духе редактора кода. Прогресс видно с одного взгляда: в шапке три шага (сделанные
зелёные) и счётчик N/3; на вкладке значок — пусто / есть код / шаг сделан / ошибка; у «Движка»
иконка настроек. Игра справа в рамке; колонка `clamp(420px, 40vw, 640px)`. Ошибка — внизу
левой колонки. Уведомления — снизу над редактором, 10 секунд (сброс всего — 30), исчезают
при печати и запуске. До 1024px колонки складываются, редактор 70vh, игра под ним; на 375px
нет горизонтальной прокрутки.

Токены: ground #141519, surface #1b1d22, panel #202228, raised #292c33, line #2d3037, ink
#dcdee3, dim #9197a1, faint #636873, accent #4fc3f7, ok #7cc47f, warn #e5b567, danger #f28b82.
Подсветка: comment #6a9955, string #ce9178, number #b5cea8, keyword #569cd6, definition
#dcdcaa, variable #9cdcfe.

  `ctx.restore()`: полупрозрачная кисть тени иначе затемняла смайлики, нарисованные после труб (браузер применяет
  прозрачность кисти и к цветным эмодзи). Готовая версия переехала на ключ `bird-sandbox-finished-v2`, чтобы старый
  сохранённый движок с этой ошибкой не остался в браузере. Корпус приставки — свой у каждой игры
  (`Lesson.consoleColor`, переменные `--shell-*` в `ui.css`): Корзинка («очень легко») — белая, Птичка
  («легко») — зелёная, и в игре, и на карточке меню; деления и подпись сложности на карточке — того же цвета.
- **Вторая игра — Птичка (версия 6, `?game=bird`)**, как Flappy Bird, уровень «легко». Новое — скорость, а не
  только позиция: каждый кадр `speedY += gravity`, `birdY += speedY`; взмах — `speedY = -flapPower`. Движок ждёт
  первого пробела («Жми пробел!»): до него птица висит и трубы стоят. Пробел, стрелка вверх или клик по холсту —
  взмах. Вкладки: «Движок», «Птица», «Взмах», «Трубы», «Удар». Квесты:
  1. «Птица»: «Создай птицу» → «Выбери птицу» → «Нарисуй птицу» (`drawBird`) → «Собери игру» → «Птица падает»
     (`moveBird` по кусочкам: гравитация к скорости, скорость к высоте, низ экрана и небо) → «Включи гравитацию»: в
     «Движке» `gravity = 0`, птица висит, поставить 0.4.
  2. «Взмах»: `flap` → «Сила взмаха» (`flapPower` с 0 на 7).
  3. «Трубы»: `movePipes` (раз в `pipeEvery` кадров труба с дыркой на случайной высоте, едут влево, за краем
     убираются) → `drawPipes` → «Скорость труб» (`pipeSpeed` с 0 на 2).
  4. «Удар»: `checkHit` (низ экрана, перебор труб, `ryadom`, удар → `gameOver = true`) → «Очко за трубу» (`passed`).

  Дополнительные задания вместо бомбы и звезды — «Монетки» 🪙 (+5 очков, в половине дырок) и «Всё быстрее» ⚡
  (каждые 10 секунд `pipeSpeed + 0.5` до `maxSpeed`). Сохранение — `bird-sandbox-v1`, готовая —
  `bird-sandbox-finished-v2` (тот же пароль). На корпусе приставки вместо ← → одна кнопка «Взмах» (шлёт пробел),
  «Границы» показывают рамку птицы, трубы и низ экрана. Конец игры по `gameOver === true` — та же карточка «Игра
  окончена». Что у игры своё (кнопки, подписи, заголовок дополнительных заданий, сцена карточки), описано в
  пакете урока: `controls`, `extrasTitle`, `card.scene`. Главное меню — две карточки в ряд, «Здесь появятся новые
  игры» — во всю ширину под ними; в окне смайликов появилась группа «Летают».
- **Под картой — одна станция (версия 11, по просьбе пользователя).** Гайд больше не длинная лента шагов: под
  картой открыт только один шаг, бонусное задание или финиш. По умолчанию — станция «ты здесь»; нажал другую на
  карте — открылась она (у её подписи светлая табличка с уголком вниз), даже закрытая — с текстом, когда откроется.
  Выбор живёт, пока ученик на той же станции: прошёл шаг — под картой сам открывается следующий. Внизу кнопки
  «Назад» и «Дальше» к соседним станциям; у пройденного шага — «Перейти к шагу N». Чек-поинты в шапке тоже
  открывают свою станцию. Скрытые шаги не размонтируются и помнят раскрытый «Готовый код».
- **Станция пройдена — момент на карте (версия 11).** Пройденная станция вспыхивает: клавиша на миг
  загорается жёлтым и подпрыгивает, выскакивает зелёная галочка, во все стороны разлетаются восемь пикселей
  (жёлтые и зелёные квадратики, как клетки рисунков). Следом жёлтая дорога дотягивается до следующей станции,
  и туда переезжает стрелка. Всё — один раз и около полутора секунд. Если шаг пройден в коде, момент ждёт,
  пока ученик вернётся в «Гайд», и карта сама поднимается в поле зрения. При `prefers-reduced-motion` — без
  вспышки и переездов: станция и стрелка сразу на новом месте.
- **Карта игры в гайде (версия 10, по просьбе пользователя).** Над шагами — карта, как карта уровней в играх:
  дорога из квадратных плиток петляет от станции к станции — шаги игры (номер и рисунок шага), бонусные задания
  (жёлтая пунктирная рамка) и финиш с подарком. Пройденная часть дороги жёлтая, пройденные станции — с зелёной
  галочкой, закрытые — серые с замком. Текущая станция мягко пульсирует, над ней — жёлтая пиксельная стрелка
  (герой на карте не прыгает — по просьбе пользователя); сменилась станция — стрелка переезжает. Над картой строка «Ты здесь:
  шаг 2 «Яблоки падают» — квест 1 из 4». Карта не уже
  620px: на телефоне листается вбок и сама встаёт на текущую станцию. Тогда же набор рисунков вырос до 53, а
  в Корзинке убран квест «Не только яблоки»: по умолчанию всегда падают яблоки.
- **Свои рисунки вместо смайликов (версия 9, по просьбе пользователя).** Все три игры рисуют картинками из
  набора TimeBox: 53 рисунка в пяти группах («Герои», «Еда», «Вещи», «Летают», «Космос») плюс «?» для
  неизвестного имени. Пиксель-арт 24×24 клетки: рисунок собирается из простых фигур, программа сама кладёт
  их на клетки с тенью снизу справа, светлой каймой сверху слева и контуром в одну клетку — поэтому свет и
  контур у всего набора одинаковые. На экране рисунок 34×34 — как прежний смайлик, рамки столкновений те же.
  Наружу рисунок уходит SVG-картинкой из прямоугольников (`crispEdges` — клетки без размытия); обвязка игры
  растеризует её в холст нужного размера (`picture(name, size)`, на HiDPI крупнее) и держит в кэше; пока
  картинка не загрузилась, холст пустой. Имена
  по-русски: ученик пишет `var shipPic = "ракета";` и `drawPic(shipPic, shipX, shipY)` — готовую функцию
  движка (низ картинки — на высоте y, как у текста). Квесты «Нарисуй…» стали на кусок короче (строка
  `ctx.font` не нужна), квесты «Выбери…» открывают окно с рисунками; у переменных `…Pic` в коде кнопка «Сменить»
  с миниатюрой. Опечатка в имени — игра рисует «?» и пишет в «Консоль», какие имена есть. Ракета стоит прямо,
  луна в Космосе — тоже рисунок. Герой Корзинки по умолчанию — колобок, птица — цыплёнок. Ключи сохранения
  учебных и готовых версий сменились (`catch-sandbox-v2`, `bird-sandbox-v2`, `space-sandbox-v2`, готовые —
  `…-finished-v2`, у Птички `bird-sandbox-finished-v3`): старый код со смайликами квесты бы не засчитали.
- **Третья игра — Космос (версия 8, `?game=space`)**, стрелялка, уровень «сложно», красный корпус. План — в
  `docs/PLAN-space.md`. Новое для ученика сразу три вещи: второй массив (пули `bullets` рядом с пришельцами
  `enemies`), вложенный цикл «каждый пришелец × каждая пуля» с `break` и перезарядка — счётчик `reload`, который
  каждый кадр уменьшается до нуля. Вкладки: «Движок», «Корабль», «Пули», «Пришельцы», «Попадание». Квесты (22):
  1. «Корабль»: «Создай корабль» → «Выбери корабль» → «Нарисуй корабль» → «Собери игру» → «Научи корабль
     летать» → «Скорость корабля» (`shipSpeed` с 0 на 6).
  2. «Пули»: «Выстрел» → «Пули летят» → «Нарисуй пули» → «Скорость пуль» (`bulletSpeed` 9) → «Сплошной луч»
     (квест-запуск: без перезарядки пуля вылетает каждый кадр) → «Перезарядка» → «Время перезарядки»
     (`reloadTime` 15) → «Цвет пуль» (`bulletColor`, палитра).
  3. «Пришельцы»: «Волна пришельцев» (пустой массив → новая волна: `waveSize` пришельцев в случайных местах, по
     одному сверху, у каждого своя скорость вбок `dx`) → «Нарисуй пришельцев» → «Скорость пришельцев»
     (`enemySpeed` 1) → «Зигзаг» (`a.x += a.dx`, у края `dx = -dx`) → «Свой пришелец» (`enemyEmoji` в «Движке»).
  4. «Попадание»: «Каждая пуля × каждый пришелец» (оба цикла с конца, `splice` обоих и `break`) → «Очко за
     пришельца» → «Пришелец прорвался» (ниже `shipY - 10` — минус жизнь; жизней три, конец — `lives <= 0`).

  Движок рисует звёзды и полупрозрачную луну 🌙 (в `ctx.save()`/`restore()`, чтобы не тускнели смайлики) и
  крупную надпись «Волна N», когда прилетает новая волна. Все массивы, включая `booms`, объявлены в «Движке».
  Дополнительные задания: «Взрывы» 💥 (третий массив `booms`, взрыв горит 20 кадров) и «Волна за волной» 🌊
  (каждая волна на 0.25 быстрее и на одного пришельца больше, пока скорость не дойдёт до `maxSpeed`).
  Сохранение — `space-sandbox-v1`, готовая — `space-sandbox-finished-v1` (тот же пароль). На корпусе ← → и широкая
  «Огонь» (шлёт пробел); «Границы» показывают рамки пришельцев как в `popal`, пули, корабль и линию прорыва.
  Сцена карточки в меню: пришельцы спускаются зигзагом по одному, корабль подъезжает, выстрел, взрыв.
  Место «Здесь появятся новые игры» встаёт рядом с последней карточкой, если игр нечётное число.
  **Заодно (версия 8):** обвязка отпускает зажатые клавиши, когда игра теряет фокус (иначе после клика мимо
  игры корабль стрелял и летел сам, а герой Корзинки ехал); шапка игры сама сжимается, когда не помещается —
  раньше на ширинах 641–1440 px она раздвигала страницу вбок у всех игр.
- **Название сайта (версия 5):** «TimeBox — конструктор игр» — заголовок вкладки, описание страницы и
  подпись рядом с логотипом в шапке (на широких экранах). У готовой версии вкладка — «TimeBox — готовая
  игра Catch». Слово «песочница» в интерфейсе больше не используется.
- **Название и шапка (версия 4):** игра называется Catch (вместо «Лови яблоки»); слева в шапке
  белый кубик — логотип TimeBox (он же значок вкладки), в гайде заголовок Catch. Кнопка
  «Запустить» переименована в «Собрать» (Ctrl+Enter), тексты гайда говорят «Собрать». Прогресс — пять
  галочек в одном ряду: три шага (зелёные) и бомба со звездой (жёлтые). После проигрыша
  посередине экрана — «Начать заново». Рамки вокруг экрана при игре нет: фокус показывает
  лампочка. Стрелки на корпусе не забирают фокус у игры.
- **Бомба и звезда (версия 4)** закрыты, пока не пройдены три шага с заданиями; звезда — после
  бомбы. У каждой две кнопки: «Добавить переменную в «Движок»» и «Вставить код в «Яблоки» и
  «Поимка»» (вторая — после первой). Код бомбы и звезды сохраняет `speedUp` и +10 очков.
- **Готовая игра под паролем (версия 4).** «Открыть готовую игру» и прямая ссылка `?finished`
  спрашивают пароль. В коде хранится только хеш, но проверка идёт в браузере: это защита от
  случайного открытия, а не настоящая. Открытие запоминается до закрытия вкладки.
- **Убрано по просьбе пользователя:** «Поделиться» (ссылка, файлы), меню «Вид» (проектор,
  размер шрифта), пауза, шаг по кадрам, замедление, всё со звуком (`playSound` и задание
  «Со звуком»).
